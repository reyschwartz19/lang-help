# Design System

> Locked before any UI code is written. Every page, component, and interaction derives from this design language. The product should feel like a polished consumer app people genuinely look forward to opening every day.

---

# Design Philosophy

Learning a language should feel exciting, rewarding, and approachable.

This is **not** a productivity tool.

This is **not** an academic reference.

This is **not** a corporate dashboard.

Every screen should communicate:

> "You're making progress."

The interface should encourage curiosity rather than discipline.

Instead of feeling like homework, studying should feel like opening a favorite game for a few minutes.

---

# Visual Direction

Imagine walking through a vibrant French neighborhood on a sunny afternoon.

Bright cafés.

Blue street signs.

Fresh pastries.

Colorful storefronts.

Friendly conversations.

Warm sunlight.

The interface should feel energetic, colorful, modern and playful without becoming childish.

# Gradients

Use gradients carefully.

Examples

French Blue → Indigo

Emerald → Mint

Golden → Orange

Only use gradients for

- Hero cards
- Primary buttons
- Progress
- Illustrations

Never use gradients on everything.

---

# Typography

Use only modern geometric sans-serif fonts.

Examples

- Geist
- Inter
- Plus Jakarta Sans
- Manrope

No serif fonts anywhere.

Typography should feel soft and approachable.

## Scale

Page Title

# Layout

The layout should feel spacious.

Large padding.

Large margins.

Generous whitespace.

Never cram information together.

Each page should have one obvious focus.

Cards should be stacked vertically.

Scrolling should feel effortless.

---

---

# Emotional Goal

Every interaction should make the learner feel

"I know more French today than I did yesterday."

The interface should build confidence.

The learner should finish each session smiling.

---

# What To Avoid

Do not generate

- Corporate SaaS dashboards
- Dark hacker themes
- Glassmorphism-heavy layouts
- Neumorphism
- Brutalism
- Academic textbook layouts
- Dense tables
- Tiny buttons
- Monochrome interfaces
- Overly serious designs
- Excessive gradients
- Clutter
- Long walls of text
- Sharp corners
- Tiny cards

---

# Final Design Goal

This should feel like one of the highest-quality educational apps available today.

The interface should immediately communicate joy, progress and momentum.

It should make learning French feel like exploring a beautiful city one small adventure at a time.

Every screen should encourage the learner to continue just one more lesson.
